# AP-Euro-Test

A split-screen multiple-choice practice test that runs in the browser. The passage is on the left and the question is on the right. There's no timer.

- **Open it:** go to `https://keerthanpadarthi-sys.github.io/AP-Euro-Test/` once GitHub Pages is on (Settings → Pages → Branch: `main`, folder `/ (root)` → Save).
- **Change the questions:** edit `questions.js`. Each question has a passage (or `null`), the question text, the answer choices, and the correct letter.
- **Features:** pick answers, cross out choices, mark questions for review, jump between questions, highlight passage text, check your work, then submit to see your score and the correct answers.

## Messages

Click **Messages** at the top right. Both people type in **your email** and **their email** (each person puts their own first). Using the same two emails puts you in the same conversation, and you can chat back and forth live.

- Messages go through [ntfy.sh](https://ntfy.sh), a free public relay, and are kept for about 12 hours. Anyone who knows both emails could read them, so don't send anything private.
- **Send as email instead** opens your email app with the message and their address already filled in.
